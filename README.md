# Astronomy Stellar Classification 🌟
Astronomical and Celestial Object Classification - Undergraduate Capstone Project (3 Credits)

## 📌 Project Overview
- **Institution:** Islamic Azad University, Karaj Branch
- **Academic Term:** Summer & Fall (4043-4051)
- **Topic:** Machine Learning & Classification of Celestial Objects (Stars, Galaxies, and Quasars)

## 🚀 Overview
This repository contains a complete end-to-end machine learning workflow for exploratory data analysis (EDA) and stellar classification using the Random Forest algorithm based on astronomical features.

## 📂 Project Structure
- `analysis.ipynb`: Main Jupyter Notebook containing data preprocessing, EDA, and model training.
- `Dataset/`: Contains the stellar classification dataset (`star_classification.csv`).
- `class_distribution.png`: Visualization showing the distribution of celestial classes (Galaxy, QSO, Star).
